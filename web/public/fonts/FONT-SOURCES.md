## Subset and usage

English files preserve the official complete Latin subsets. The Noto Sans SC files are official API-generated text subsets of 862 distinct CJK and non-Latin punctuation/symbol codepoints collected from every staged src text file and index.html. The subsets contain no ASCII text, so their unicode-range declarations cannot capture Latin text intended for Geist Mono or Source Code Pro.

The same declarations are integrated at the beginning of src/styles.css using /fonts/ asset paths, which Vite rewrites to relative ../fonts/ URLs for the existing base: ./ build. font-faces.css is retained as a reusable standalone source with relative URLs; index.html does not link a second font stylesheet. Suggested heading stack: 'Geist Mono', 'Noto Sans SC', ui-monospace, monospace. Suggested body/navigation stack: 'Source Code Pro', 'Noto Sans SC', ui-monospace, monospace.

All WOFF2 signatures and declared file lengths were checked. Requested CJK codepoints were compared against the official CSS unicode-range declarations. The runtime has no fontTools/Brotli, so binary cmap decoding was not performed; browser loading/rendering must be checked by the integration task. Regenerate subsets when adding new Chinese characters; missing characters otherwise use the browser fallback. Detailed source CSS, requested codepoints and source URLs are retained in font-acquisition/font-manifest.json in the staging directory.
